# 📊 Data Jobs Dashboard | Power BI

An interactive Power BI dashboard for exploring the 2024 data job market, analyzing salary trends, comparing job titles, and understanding the global distribution of data-related job opportunities.

## 🔗 Interactive Dashboard

![Data Jobs Dashboard Page 1](/images/dashboard_1.jpg)

## 📌 Project Overview

The **Data Jobs Dashboard** was developed to help job seekers, career changers, and professionals exploring new opportunities better understand the data job market.

Job market information can be scattered across different platforms, making it difficult to compare salaries, identify in-demand roles, and understand hiring trends. This project uses a real-world dataset of 2024 data science job postings to bring relevant information together in an interactive dashboard.

Using Microsoft Power BI, the dashboard transforms raw job posting data into meaningful visual insights, helping users explore job demand, salary distributions, remote work opportunities, and job locations.

## 🎯 Project Objectives

- Analyze the distribution of data-related job opportunities.
- Compare median annual salaries across different job titles.
- Identify job titles with high demand in the data industry.
- Explore job opportunities across countries and regions.
- Examine work-from-home opportunities and hiring platforms.
- Build an interactive report that supports data-driven career exploration.

## 🛠️ Tools and Technologies

- **Microsoft Power BI:** Dashboard development and data visualization.
- **Power Query:** Data cleaning, transformation, and preparation.
- **DAX and Power BI Calculations:** KPI calculations and analytical metrics.
- **Data Visualization:** Charts, cards, maps, and tables.
- **Interactive Reporting:** Slicers, buttons, bookmarks, and drill-through navigation.

## 💡 Skills Demonstrated

### 1. Data Cleaning and Transformation

Used Power Query to prepare the raw dataset for analysis by handling missing values, adjusting data types, and creating additional columns where necessary.

### 2. Data Analysis and KPI Development

Analyzed job postings and salary information to generate key performance indicators, including job count and median yearly salary.

### 3. Data Visualization

Created visualizations to communicate job market insights effectively, including:

- Bar and column charts for comparing job titles and salaries.
- Line and area charts for examining trends.
- Map charts for exploring geographical job distributions.
- KPI cards for displaying important metrics.
- Tables for detailed job market information.

### 4. Interactive Dashboard Design

Implemented interactive reporting features to improve the user experience:

- **Slicers:** Filter the dashboard by job title.
- **Buttons and Bookmarks:** Navigate between report views.
- **Drill-through:** Explore detailed information for a selected job title.
- **Dynamic Filtering:** Interact with visualizations to examine specific aspects of the data.

### 5. Analytical Storytelling

Organized the dashboard into summary and detailed analysis pages, enabling users to move from an overview of the job market to more specific insights.

## 📈 Dashboard Overview

The report consists of two main pages.

### Page 1: Data Jobs Market Overview

![Data Jobs Dashboard Page 1](/images/dashboard_1.jpg)

This page provides a high-level overview of the data job market, presenting key metrics and visualizations to help users understand the distribution of job opportunities and salary trends.

**Key insights explored:**

- Total number of job postings.
- Median yearly salaries across data-related roles.
- Comparison of job demand across job titles.
- Geographical distribution of job opportunities.
- General patterns in data job compensation.

### Page 2: Job Title Drill-Through Analysis

![Data Jobs Dashboard Page 2](/images/dashboard_2.jpg)

This page provides a more detailed analysis of an individual job title. Users can drill through from the overview page to examine information specific to their selected role.

**Key insights explored:**

- Salary ranges and median compensation.
- Work-from-home opportunities.
- Popular platforms for finding job postings.
- Geographical distribution of opportunities.
- Detailed information associated with the selected job title.
